## Functions
- Songs suggests

## Commands

| Command             | Description                     |
|---------------------|---------------------------------|
| /start              | Start Bot                       |
| /id                 | Get your own ID                 |
| /id @username       | Get ID by username              |
| /id [with reply]    | Get ID of message author        |
| /info               | Get your own INFO               |
| /info @username     | Get INFO by username            |
| /info [with reply]  | Get INFO of message author      |
| /chat               | Get chat ID                     |
| /ban @              | Ban user                        |
| /unban @            | Unban user                      |
| /op [with reply]    | Make user admin                 |
| /unop [with reply]  | Make user not admin             |
| /unop @             | Make user not admin vy username |
| /banlist            | Get list of banned users        |
| /adminlist          | Get list of admins              |
| /alarm [with reply] | Alarm admins to message         |
| /announce [text]    | Make an announce in bot         |
